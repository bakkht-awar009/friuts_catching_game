# 🍎 Fruit Catching Game

A fun and interactive browser-based game where the player catches falling fruits to score points. Built using core web technologies as a beginner project to practice JavaScript game logic and DOM manipulation.

## Features
- Multi-level progression — speed increases as your score goes up
- Real-time collision detection between fruits and the catcher
- Interactive UI with live score tracking
- Simple and responsive gameplay controls

## Technologies Used
- HTML
- CSS
- JavaScript
